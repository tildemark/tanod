Privacy Policy & Data Sovereignty Attestation

Effective Date: October 1, 2026 • Governed by Republic Act No. 10173 (Data Privacy Act of 2012)

🛡️ Executive Privacy Commitment

TANOD Desktop is engineered under a foundational principle: "A Data Protection Officer's compliance records are privileged corporate assets that must never leave their local workstation." Neither the software application nor this landing website collects, tracks, analyzes, sells, or transmits personal data or corporate compliance logs to any external server.

01. TANOD Desktop Native Application

The TANOD Windows desktop application operates entirely on an offline-first, local-first paradigm.

  • Local Database Isolation: All Records of Processing Activities (ROPA), Privacy Impact Assessments (PIA), incident and breach records, Data Subject Rights (DSR) logs, and statutory vault documents are written directly to a local SQLite database stored in your Windows AppData directory (%APPDATA%\tanod\tanod.db).
  • Zero Outbound Telemetry: The desktop software contains no tracking scripts, product analytics, error telemetry beacons, or crash reporters. No network requests are initiated by the application during normal compliance operations.
  • No Cloud Sync: There is no cloud multi-tenancy, third-party backend database, or hosted synchronizer. You retain 100% legal custody and sovereignty over all data.
  • Disaster Recovery Portability: Backups created via the Disaster Recovery module generate an encrypted, self-contained .tanod file saved directly to your local file path or secure offline drive.

02. Landing Page & Distribution Website (tanod.sanchez.ph)

This website serves strictly as an informational portal and distribution vehicle for the open-source Windows installer binaries.

  • No Cookies & No Session Trackers: We do not set first-party or third-party cookies, tracking pixels, browser fingerprinting scripts, or persistent local storage identifiers.
  • No Advertising or Profiling: We do not participate in behavioral ad networks, data brokering, or remarketing campaigns.
  • Direct Installer Links: Download buttons on this site link directly to the compiled release assets hosted transparently on GitHub Releases. When your browser queries the GitHub API to display the latest release tag, that request is handled under GitHub's standard public API policies.

03. Strict Compliance with Philippine Data Privacy Act (RA 10173)

TANOD's architecture is deliberately structured to eliminate statutory liability under the General Data Privacy Principles of Republic Act No. 10173:

Transparency

The entire source code is open, inspectable, and auditable on GitHub under the MIT License.

Legitimate Purpose

Data is processed solely within your own workstation for statutory DPO duties under NPC circulars.

Proportionality

Zero data collection represents the highest standard of data minimization under DPA Section 11.

04. Cryptographic Integrity & Tamper Evidence

All statutory system actions within TANOD Desktop are recorded in an append-only, SHA-256 hash-chained audit ledger. This guarantees that your internal regulatory records cannot be repudiated or surreptitiously altered, ensuring strict compliance with National Privacy Commission evidentiary expectations.
