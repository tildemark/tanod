SOVEREIGN DATA ARCHITECTURE

Why Desktop & Offline Matters for RA 10173 Compliance

Under Philippine law, your organization's ROPA and PIA contain highly confidential maps of internal databases, security vulnerabilities, and employee/customer records. Storing this compliance telemetry on third-party cloud servers introduces unnecessary regulatory exposure.

✓ 100% Offline SQLite Engine: All records stored locally in %APPDATA%\tanod\tanod.db
✓ Zero Telemetry: No analytics trackers, no cloud callbacks, no third-party APIs.
✓ Tauri v2 + Rust Core: Ultra-lightweight ~15MB Windows binary compiled natively for speed and memory safety.
